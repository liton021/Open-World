How people make awesome car games with AI

This whole game is a demo of the 2026 workflow: a coding agent (three.js + Vite) builds the world, the car, the physics and the HUD from prose, while generative tools fill in art and sound. The full write-up lives in docs/MAKING-AN-AI-CAR-GAME.md in this repo.

  1. Prompt-to-playable — Rosebud AI, Astrocade, Cinevva, or a plain Claude/ChatGPT canvas turn one paragraph into a playable build.
  2. Prompt-to-code — Cursor / Claude Code / this agent iterate on a real three.js repo so you own the source.
  3. Generative assets — Meshy, Tripo and Rodin make GLB cars; Scenario and Layer do textures and skyboxes; ElevenLabs and Suno do voice and music.
  4. Game feel — the part AI still needs you for: tune grip, camera lag, bloom, FOV kick until it feels fast.
  5. Ship — one `vite build`, push to GitHub Pages / Vercel, and share the link.
